# Secure Login System 🔐

## Project Overview
A simple secure login system built using Flask with password hashing and session management.

## Features
- User Registration
- User Login
- Password Hashing (bcrypt)
- Session-based Authentication
- Logout Feature
- SQL Injection Safe Queries

## Technologies Used
- Python
- Flask
- Flask-Bcrypt
- SQLite (default backend)

## How to Run
```bash
python app.py
